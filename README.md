# Une démarche de développement MVC en Web/PHP4

➡️ Cours associé : **[Méthodologie de développement MVC d'une application web en PHP4](https://stahe.github.io/php4mvc-janvier-2004/)**

Ce document présente une **démarche de développement d’applications Web en PHP respectant l’architecture MVC (Model–View–Controller)**.

L’objectif n’est pas de fournir une méthode rigide mais plutôt **d’ouvrir des pistes de réflexion et de structuration** pour la conception d’applications Web organisées selon le modèle MVC. Chaque développeur pourra ensuite adapter cette démarche **à ses besoins, à ses outils et à ses préférences de développement**.

## Objectif du document

- proposer une **méthodologie de développement** pour les applications Web en PHP
- structurer une application selon le **patron d’architecture MVC**
- clarifier la séparation des responsabilités entre :
  - le **modèle (Model)** : gestion des données et de la logique métier
  - la **vue (View)** : présentation et interface utilisateur
  - le **contrôleur (Controller)** : orchestration des interactions entre modèle et vue

Cette démarche vise à améliorer :

- la **maintenabilité du code**
- la **lisibilité de l’architecture**
- la **réutilisation des composants**
- la **séparation claire des responsabilités**

## Philosophie de la démarche

La méthodologie proposée est volontairement **ouverte et adaptable**.  
Elle constitue un **guide de structuration** plutôt qu’un cadre strict.

Chaque équipe ou développeur pourra :

- adapter les conventions
- modifier l’organisation des composants
- intégrer des frameworks ou bibliothèques complémentaires
